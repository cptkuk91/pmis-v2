# PMIS Version Roadmap & Backlog

## 현재 기준

- 현재 저장소 버전: `2.0.0`
- 현재 기준선: 관리직 중심 PMIS 운영 기능 완성 및 QA/QC 실운영 화면 반영
- 기준일: `2026-03-13`

---

## 오픈소스 지원 범위

- 오픈소스 공개 및 공식 유지보수 범위는 `Version 2.5 이전` 라인업까지만 고려한다.
- 현재 기준으로는 `Version 2.0.x`가 오픈소스 공식 지원 대상이다.
- `Version 2.5`는 내부 PoC/실험 단계로 취급하며, 공개 범위는 별도 재검토한다.
- `Version 3.0` 이상은 비공개 또는 제한 공개 전략을 전제로 검토한다.

---

## Version 라인업

아래 감축/향상 수치는 현장 규모와 자동화 범위에 따라 달라질 수 있는 추정치다.

| Version | 주 대상 | 현재 상태 | 오픈소스 지원 | 메모 |
|---|---|---|---|---|
| 2.0 | 관리직 | 현재 운영 기준선 | 지원 | QA/QC 운영 모듈 반영 완료 |
| 2.5 | 관리직 + AI 보조 | PoC 예정 | 미정 | AI 보조 입력/분석 단계 |
| 3.0 | 현장직 + SmartGlass | 기획 | 미지원 | 웨어러블 기반 현장 입력 |
| 3.5 | 현장직 + SmartGlass + AI | 기획 | 미지원 | 자동 입력 전환 목표 |
| 4.0 | Robot | 장기 로드맵 | 미지원 | 로봇/센서 기반 현장 자동화 |

## Version 2.0 반영 확인

확인 결과, 아래 항목은 현재 코드베이스에 반영되어 있다.

### 실운영 화면 확장

- QA 모듈 운영 화면 반영
  - 품질 정책·목표
  - 품질보증계획(QAP)
  - 표준 절차·템플릿
  - 내부 심사
  - CAPA
  - 협력사 품질보증
  - 품질 KPI
- QC 모듈 운영 화면 반영
  - 검사·시험 계획(ITP)
  - 자재 검사
  - 공정 검사
  - 시험 성적서
  - NCR
  - 인수·준공 검사
  - 품질 대시보드

### 대시보드/업무 흐름 보완

- 대시보드 카드 이동 경로 정리
  - 결재 대기 문서
  - 금일 회의
  - 공지사항
  - 도면 검토 대기
  - 오픈 이슈
- QA/QC 운영 경고 연계 반영
  - 미완료 내부 심사
  - 기한 경과 CAPA
  - 경고 KPI
  - 지연 NCR
  - 미조치 인수·준공 검사

### 설계·문서/공통 운영 보완

- 도면검토 등록 흐름 보완
  - 문서번호 자동 채번
  - 검토자 현장 인력 선택
- 회의/이슈 삭제 확인을 공용 모달로 통일
- 회의 주관자를 현재 사용자 기준으로 고정
- 운영 문서/README/정적 자산 정리
  - README 최신화
  - 운영 매뉴얼 보정
  - 파비콘 교체
  - 라이선스 추가

## Version 2.0 후속 보완 Backlog

아래 항목은 `2.0.x` 유지보수 범위에서 계속 보완할 수 있는 과제다.

### 코드 등록/채번 자동 생성

- 통합 채번 규칙 서비스 확대
  - 문서번호 외 회의번호, 티켓번호, 이슈번호 등 공통 규칙 정리
- 사이트 단위 유니크 인덱스 및 충돌 방지 정책 점검

### 현장 개설 자동화

- `POST /api/sites` 완료 후 초기 세팅 자동화
  - 기본 코드 그룹/기준값 생성
  - 기본 외부 링크 생성
  - 현장 개설 체크리스트 제공

### 사용자-현장 배정 운영성 강화

- 미배치 사용자 큐 분리
- 배정/해제 이력 상세 감사 로그 정리
- 대량 배정/대량 권한 변경 기능

### 데이터 입력 품질 고도화

- 기준정보 참조형 입력 확대
- 전화번호/이메일/날짜/금액 검증 룰 통일
- 핵심 키 조합 중복 등록 방지 강화

### 운영 안정화

- Open-Meteo 연계 안정화
  - 재시도/backoff
  - 캐시/TTL
  - 장애 가시화
- 배치/연계 상태판 제공
- 장애 점검 커맨드와 Runbook 일치화

### UI/업무 효율 개선

- 통합 검색 범위/최근 검색어 개선
- 등록 폼 UX 표준화
- 모바일 대응 우선 화면 추가 보정

## Version 2.5

### 방향

- 관리직 중심 업무에 `AI 보조 입력`과 `AI 요약/분류`를 도입하는 단계
- 현장직 직접 입력은 유지하고, 관리직 반복 업무를 줄이는 데 집중

### 목표

- 관리직 인력 감축 예상: `30%`
- 현장직 인력 감축 예상: `0%`
- 작업 속도 향상 예상: `20~30%`

### 주요 과제

- AI 문서 분류 및 제목/메타 추천
- 회의록 자동 요약 및 액션 아이템 추출
- 이슈/문의 자동 분류 및 우선순위 추천
- QA/QC 입력 보조
  - CAPA 초안 제안
  - NCR 원인분석 초안 제안
  - KPI 경고 해석 보조
- 도면/문서/OCR 기반 메타데이터 추출 PoC

### 비고

- `2.5`는 기능 실험과 운영 검증이 핵심인 PoC 단계다.
- 오픈소스 공식 지원 대상에는 포함하지 않는다.

---

## Version 3.0

### 방향

- `SmartGlass` 기반 현장 입력을 도입해 현장직의 손 입력을 줄이는 단계
- 관리직과 현장직 사이의 데이터 전달 지연을 줄이고 실시간 보고 체계를 만든다.

### 목표

- 관리직 인력 감축 예상: `35~45%`
- 현장직 인력 감축 예상: `5~10%`
- 작업 속도 향상 예상: `35~45%`

### 주요 과제

- SmartGlass 기반 점검/검사 입력
- 음성 명령 기반 작업일지/점검일지 작성
- 사진/영상/음성의 현장 단위 즉시 업로드
- 위치/공정/작업자 자동 매핑
- 현장 이벤트 실시간 동기화
  - 안전 이상
  - 품질 이슈
  - 설계 변경 지시

---

## Version 3.5

### 방향

- SmartGlass와 AI를 결합해 `현장직 직접 기입 최소화`를 목표로 하는 단계
- 수집된 비정형 입력을 구조화 데이터로 자동 전환한다.

### 목표

- 관리직 인력 감축 예상: `50~60%`
- 현장직 인력 감축 예상: `40~55%`
- 작업 속도 향상 예상: `60~70%`

### 주요 과제

- 음성/영상 기반 자동 입력
- 검사 항목 자동 체크 제안
- AI 기반 NCR/CAPA 자동 초안 생성
- 공정/품질/안전 이상 징후 조기 탐지
- 현장 보고서 자동 생성
- 사람 검토 후 승인하는 `AI-first` 운영 모델 구축

---

## Version 4.0

### 방향

- 로봇/센서/비전 기반 현장 자동화를 도입하는 장기 단계
- 사람은 승인과 예외 처리 중심으로 이동하고, 반복 점검과 수집은 기계가 수행한다.

### 목표

- 관리직 인력 감축 예상: `60~75%`
- 현장직 인력 감축 예상: `80~90%`
- 작업 속도 향상 예상: `80~90%`

### 주요 과제

- 로봇 기반 품질/안전 순찰
- 자재/공정/설비 상태 자동 스캔
- 드론/로봇/고정 센서 데이터 통합
- Digital Twin 기반 현장 상태 시각화
- 자율 점검 결과의 PMIS 자동 반영
- 예외 상황만 사람이 승인하는 운영 모델 구축

---

## 정리

- `Version 2.0`은 현재 코드 기준의 운영 버전이다.
- `Version 2.0.x`는 실무 안정화와 자동화 보완에 집중한다.
- `Version 2.5`는 AI 보조 단계다.
- `Version 3.0`부터는 SmartGlass 기반 현장 입력 전환이 핵심이다.
- `Version 3.5`는 AI 자동 입력, `Version 4.0`은 Robot 자동화 단계다.
- 오픈소스 공식 지원은 `Version 2.5 이전` 범위까지만 고려한다.
