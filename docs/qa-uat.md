# QA 운영자 테스트 시나리오 초안

## 시나리오 1. 품질 목표에서 KPI까지 연계

1. `/qa/policy-goals`에서 운영중 품질 목표를 등록한다.
2. `/qa/kpi`에서 정책 목표를 연결해 KPI를 생성한다.
3. 목표값, 경고 기준, 담당자가 기본 반영되는지 확인한다.
4. KPI 상세 모달에서 목표선과 실적 추이 차트가 표시되는지 확인한다.

기대 결과

- KPI 생성이 성공한다.
- 정책 목표 연계 정보가 목록과 상세에 표시된다.
- 경고 기준 이탈 시 경고 배지가 표시된다.

## 시나리오 2. 내부 심사와 CAPA 연계

1. `/qa/audits`에서 금일 또는 과거 예정일의 심사를 등록한다.
2. 체크리스트에 부적합 항목을 입력하고 CAPA 필요로 표시한다.
3. `/qa/capa`에서 해당 항목을 조치로 생성한다.
4. 기한을 과거로 설정한 뒤 대시보드와 알림에 반영되는지 확인한다.

기대 결과

- 미완료 심사 카드가 증가한다.
- 기한 경과 CAPA 카드와 알림 항목이 증가한다.

## 시나리오 3. 협력사 평가와 KPI 경고

1. `/qa/partner-assurance`에서 낮은 점수의 평가를 등록한다.
2. `/qa/kpi`에서 협력사 평균 점수 또는 고위험 건수 KPI를 확인한다.
3. 경고 기준을 넘거나 미달하는 경우 알림과 대시보드에 반영되는지 확인한다.

기대 결과

- KPI 경고 건수가 증가한다.
- 상단 알림에 `경고 KPI` 항목이 생성된다.

## 시나리오 4. 권한 점검

1. `viewer` 권한 계정으로 QA 화면에 접근한다.
2. 목록/상세 조회는 가능한지 확인한다.
3. 등록/수정/삭제 버튼 또는 API 호출이 차단되는지 확인한다.

기대 결과

- 조회는 가능하다.
- 변경 작업은 차단된다.

## 시나리오 5. 목록 정렬과 첨부 확인

1. `/qa/policy-goals`, `/qa/audits`, `/qa/capa`, `/qa/partner-assurance`, `/qa/kpi`에서 `정렬` 값을 바꾼다.
2. 첫 행 또는 상위 카드의 순서가 선택한 기준에 맞게 바뀌는지 확인한다.
3. `/qa/procedures`에서 첨부가 있는 항목의 `첨부 열기` 또는 상세 모달의 `첨부 다운로드`를 실행한다.

기대 결과

- 정렬 기준 변경 시 현재 페이지 목록 순서가 즉시 바뀐다.
- 필터와 정렬을 함께 사용해도 조회 오류가 발생하지 않는다.
- 절차서 첨부 또는 외부 링크가 정상적으로 열린다.

## 2026-03-12 반영 사항

- QA 상단 메뉴를 모바일 가로 스크롤 방식으로 정리했다.
- QA 공통 필터 패널에 `필터 초기화`와 상태 배너 패턴을 맞췄다.
- 절차서 첨부 열기/다운로드 흐름을 보강했다.
- QA 주요 목록에 정렬 선택을 추가했다.
