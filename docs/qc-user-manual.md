# QC 사용자 매뉴얼 초안

## 1. 공통

- QC 메뉴는 `/qc`에서 접근한다.
- 모든 데이터는 현재 선택된 현장 기준으로 조회된다.
- 조회는 `viewer` 이상, 등록/수정/삭제는 `manager` 이상 권한이 필요하다.
- QC 상단 메뉴는 모바일에서 가로 스크롤 방식으로 동작한다.
- 대부분의 QC 목록은 상단 `검색 및 필터` 패널에서 검색, 상태 필터, `정렬`을 함께 바꿔 사용할 수 있다.
- 빈 목록, 불러오기 오류, 저장 결과는 화면 상단 배너와 목록 하단 안내 문구로 확인한다.

## 2. 검사·시험 계획 (ITP)

- `/qc/itp`에서 공종, 세부 공정, 검사 기준, Hold/Witness 포인트를 관리한다.
- ITP는 이후 자재 검사, 공정 검사, 인수·준공 검사의 기준 데이터로 연결된다.
- 복제 기능으로 유사 공종 계획을 빠르게 만들 수 있다.

## 3. 자재 검사

- `/qc/material-inspection`에서 반입 자재의 규격, 공급사, LOT, 검사 결과를 기록한다.
- 검사 체크리스트, 판정 사유, 보류/반출 상태, NCR 연결 여부를 함께 관리한다.
- 목록과 상세 모달에서 첨부 개수와 `첨부 열기` 링크를 바로 확인할 수 있다.

## 4. 공정 검사

- `/qc/process-inspection`에서 위치, 공정 단계, 검사일, 검사 결과를 관리한다.
- ITP 체크포인트를 참조해 체크리스트를 채우고 시정조치 요청 상태를 추적한다.
- 첨부 사진과 보고서를 업로드한 뒤 상세 모달에서 바로 열 수 있다.

## 5. 시험 성적서

- `/qc/test-reports`에서 시험 종류, 시료 위치, 기준치, 측정값, 판정 결과를 관리한다.
- 자재 검사 또는 공정 검사 결과를 참조해 성적서를 등록할 수 있다.
- 기준 미달 시 NCR 검토 또는 연결 상태를 함께 관리한다.

## 6. NCR

- `/qc/nonconformance`에서 부적합 제목, 원인, 조치 계획, 담당자, 기한을 관리한다.
- 자재 검사, 공정 검사, 시험 성적서를 근거 데이터로 연결할 수 있다.
- 지연 NCR은 대시보드와 상단 알림에서 함께 확인된다.

## 7. 인수·준공 검사

- `/qc/handover-inspection`에서 세대, 공간, 공용부 기준의 인수 또는 준공 검사를 관리한다.
- 체크리스트별 보완 요청, 완료 메모, 승인 요청 상태를 기록한다.
- 미조치 finding 또는 승인 요청 상태는 QC 대시보드와 알림에 반영된다.

## 8. 품질 대시보드

- `/qc/quality-dashboard`에서 자재 합격률, 공정 미조치, 시험 기준치 이탈, NCR, 인수·준공 리스크를 한 번에 확인한다.
- 기간 필터는 최근 3개월, 6개월, 12개월 기준으로 바꿔볼 수 있다.
- 경고 카드의 링크로 NCR, 인수·준공 검사, 시험 성적서, 공정 검사 화면으로 바로 이동할 수 있다.

## 9. 운영 체크 포인트

- 메인 `/dashboard`에도 `QC 운영 리스크` 섹션이 표시된다.
- 상단 알림에는 지연 NCR과 미조치 인수·준공 검사가 표시된다.
- 샘플 데이터가 필요하면 `npm run db:seed:qc`로 현장별 QC 예시 데이터를 넣을 수 있다.
