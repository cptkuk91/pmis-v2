# QC 운영자 테스트 시나리오 초안

## 시나리오 1. ITP부터 자재 검사까지 연결

1. `/qc/itp`에서 골조 또는 마감 공종의 ITP를 등록한다.
2. `/qc/material-inspection`에서 해당 ITP 체크포인트를 참조한 자재 검사를 등록한다.
3. 체크리스트 결과와 판정 사유, 보류/반출 여부를 입력한다.

기대 결과

- 자재 검사 등록이 성공한다.
- ITP 제목과 체크포인트가 목록 또는 상세에 표시된다.
- 결과와 disposition 배지가 선택값에 맞게 표시된다.

## 시나리오 2. 공정 검사와 시험 성적서 연계

1. `/qc/process-inspection`에서 시정조치가 필요한 공정 검사를 등록한다.
2. `/qc/test-reports`에서 해당 공정 또는 자재 검사를 참조한 시험 성적서를 등록한다.
3. 기준치보다 낮은 측정값을 입력해 자동 판정이 부적합으로 나오는지 확인한다.

기대 결과

- 공정 검사와 시험 성적서가 각각 저장된다.
- 시험 판정이 자동 계산된다.
- 시험 부적합 건이 QC 대시보드 경고 항목에 반영된다.

## 시나리오 3. NCR과 대시보드 연계

1. `/qc/nonconformance`에서 자재 검사, 공정 검사, 시험 성적서를 참조한 NCR을 등록한다.
2. 기한을 과거 날짜로 설정해 지연 NCR 상태를 만든다.
3. `/qc/quality-dashboard`와 상단 알림에서 지연 NCR이 표시되는지 확인한다.

기대 결과

- NCR 등록이 성공한다.
- `지연 NCR` 경고 카드와 상단 알림 건수가 증가한다.
- NCR 상세에서 참조 검사/시험 정보가 확인된다.

## 시나리오 4. 인수·준공 검사 follow-up 흐름

1. `/qc/handover-inspection`에서 보완이 필요한 인수 검사를 등록한다.
2. checklist 항목에 finding과 보완 요청 기한을 입력한다.
3. 승인 상태를 `requested`로 두고 `/qc/quality-dashboard`를 확인한다.

기대 결과

- 미조치 finding 수가 상세와 목록에 표시된다.
- QC 대시보드와 상단 알림에 미조치 인수·준공 검사가 반영된다.

## 시나리오 5. 정렬, 첨부, 모바일 메뉴 확인

1. `/qc/material-inspection`, `/qc/process-inspection`, `/qc/test-reports`, `/qc/nonconformance`, `/qc/handover-inspection`에서 `정렬` 값을 바꾼다.
2. 각 화면에서 첨부 파일을 업로드하고 상세 모달의 `첨부 열기` 링크를 실행한다.
3. 모바일 폭 또는 브라우저 축소 상태에서 QC 상단 탭이 가로 스크롤로 동작하는지 확인한다.

기대 결과

- 정렬 기준에 따라 목록 순서가 즉시 변경된다.
- 첨부 링크가 정상적으로 열린다.
- 모바일 폭에서도 상단 메뉴 접근이 막히지 않는다.

## 시나리오 6. 권한 점검

1. `viewer` 권한 계정으로 QC 화면에 접근한다.
2. 목록/상세 조회는 가능한지 확인한다.
3. 등록/수정/삭제 API 또는 버튼이 차단되는지 확인한다.

기대 결과

- 조회는 가능하다.
- 변경 작업은 차단된다.

## 2026-03-13 반영 사항

- `/qc/quality-dashboard`와 `/dashboard`에 QC 운영 리스크 요약을 추가했다.
- 상단 알림에 지연 NCR과 미조치 인수·준공 검사를 연동했다.
- QC 상단 메뉴를 모바일 가로 스크롤 방식으로 정리했다.
- `db:seed:qc`가 자재, 공정, 시험, NCR, 인수검사 샘플까지 함께 생성하도록 확장됐다.
